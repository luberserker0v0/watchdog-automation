# WatchDog 1.0.0

WatchDog 1.0.0 is the first stable release candidate. It targets Windows x64
and provides visual pipeline authoring and execution, native screen and window
capture, OCR and other recognizers, guarded input actions, Patrol VLM
observability and recovery advice, action recording, and task notifications.

The Git tag and GitHub release are created only after the native acceptance
walkthrough in `docs/release-readiness.md` is complete.

## Distribution files

- `watch-dog_1.0.0_x64-setup.exe`: NSIS installer for the production app.
- `watch-dog-1.0.0-windows-x64.zip`: portable production, Tester, and Sample
  Target executables with required resources and native libraries.
- SHA-256 checksums and the portable content manifest accompany the artifacts.

The installer is currently unsigned. Windows may therefore show an unknown
publisher warning.

## Platform support

- Windows 10 or later, x64.
- DirectML acceleration is bundled for OCR. Environments where DirectML cannot
  initialize use the documented CPU fallback.
- Task notifications and Action Recorder native hooks are implemented for
  Windows. Other desktop platforms are outside this release.
- Patrol requires a user-configured OpenAI-compatible vision endpoint and does
  not include endpoint credentials.

## Compatibility commitments for 1.x

The following public contracts are intended to remain backward compatible
through the 1.x series:

- pipeline Mermaid, metadata JSON, and layout JSON formats;
- Tauri command names and request payloads used by the shipped frontend;
- runtime event names and existing payload fields;
- persisted preference keys;
- packaged user pipeline directory behavior.

Compatible additions may introduce optional fields, commands, event variants,
or settings. Any required migration will be documented in a later release.

## Highlights

- Source-preserving pipeline authoring with reusable templates, instances, and
  parameters.
- Explicit Entry and Endpoint lifecycle nodes with validated graph routing.
- Window foreground enforcement before input actions and visible cleanup
  diagnostics.
- Stable-screen waits before and after actions.
- Patrol state matching, action-effect verification, recovery hints, and
  guarded redirection with a structured Chat Room.
- Windows Action Recorder with elapsed action timing and JSON export.
- English and Traditional Chinese user interfaces.

See `CHANGELOG.md` for the full change list and `docs/tutorials/README.md` for
the user guide.
