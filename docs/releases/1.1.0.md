# WatchDog 1.1.0

WatchDog 1.1.0 is the first updater-enabled release. Existing 1.0.0 users must
install it manually; later signed releases can be installed from the persistent
update banner or **Settings → Application updates**.

## Highlights

- Added a determinate splash screen and startup preload sequence.
- Migrated preferences, resources, generated evidence, logs, and exports to
  Tauri application directories with safe legacy-data migration.
- Replaced custom persistence and logging with Tauri Store and Log plugins and
  scoped Action Recorder export through the FS plugin.
- Added production-only Tauri Updater integration with idle-runtime guards,
  localized status, plain-text release notes, progress, retry, and passive NSIS
  installation.
- Added tag-driven signed Windows publishing with independent Tauri updater and
  Authenticode verification.

## Compatibility

Pipeline files, metadata schemas, IPC command names, routes, and event payloads
remain compatible. Tester, Splash, Preview, and Sample Target do not receive
updater permissions. The Patrol API key remains session-only.

## Installation note

Install 1.1.0 manually from the GitHub Release. Portable users who accept a
later update transition to the normal NSIS-installed application.
